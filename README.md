# AI Upload Guard — Local Pre-upload Review (Windows)

AIや外部サービスにファイルを渡す前に、ローカルで検査できる範囲を確認する補助ツールです。

**最短操作:** ファイルを選択（自動で事前検査）→ 結果の「BLOCK / REVIEW / LIMITED」と「未検査」欄を確認 → 必要な場合のみ限定的な変換コピーを出力 → 目視確認。検査に合格してもアップロードの安全性は保証しません。

対応する検査はファイル拡張子・サイズ・一部のテキスト候補・Officeコンテナ指標・PDFメタデータと先頭ページの抽出可能テキスト・画像EXIF/GPS/ICCの一部です。氏名、住所、顧客番号、画像内文字、埋め込みファイル、全機密情報の検出には対応していません。

**限定コピー:** テキスト形式は認識できたメール・電話番号候補のみ置換します（長い数値の自動削除は行いません）。画像は再エンコードで一部メタデータを除去します。PDFは文書情報とXMPのみを対象にします。DOCX/XLSXは現在スキャン専用です。出力後の再検査でも「機密情報が完全に削除された」とは証明できません。

元ファイルと既存の出力ファイルは上書きしません。詳細な制限、テスト方法、販売ゲートは [WINDOWS.md](WINDOWS.md) に記載しています。

**販売判定：HOLD**。これは開発用ブランチであり、正式MSIXでもStore提出済み製品でもありません。

## GUIと限定コピーの再検証（2026-10-19）

`ui/safe-product-upgrade-20261019`では BLOCK/REVIEW/LIMITED/未検査の件数を画面上に表示。DOCX/XLSXは**検査専用・変換しない**ことを明示し、混在したファイル群でのスキップ件数も報告します。対応範囲の新規コピーを作る場合、処理中の入力ファイル変更を検出して生成コピーを破棄します。

「LIMITED」は検査範囲内で候補が見つからなかった意味のみで、AIアップロードの安全を保証しません。本文画像、PDFの未抽出部分やOffice全構造への完全対応は未実装です。
